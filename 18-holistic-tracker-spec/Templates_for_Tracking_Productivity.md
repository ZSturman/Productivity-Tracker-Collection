# Templates for Tracking Productivity

## Project-Oriented Productivity Template

1. **Project Overview**
   - Project name
   - Project description
   - Start date
   - End date (or deadline)
   - Project status
   - Overall progress
   - Notes

2. **Project Goals and Milestones**
   - Goal/milestone description
   - Category
   - Priority
   - Start date
   - End date
   - Status
   - Progress
   - Notes

3. **Task List**
   - Task name
   - Associated goal/milestone
   - Category
   - Priority
   - Start date
   - End date
   - Status
   - Time spent
   - Notes

4. **Time Tracking (per task)**
   - Date
   - Task name
   - Start time
   - End time
   - Duration
   - Notes

5. **Weekly Project Review**
   - Week starting date
   - Completed tasks
   - In-progress tasks
   - Upcoming tasks
   - Challenges encountered
   - Project progress update
   - Adjustments to project plan or priorities

6. **Project Post-Mortem**
   - Project name
   - Start date
   - End date
   - Goals and milestones achieved
   - Challenges faced
   - Lessons learned
   - Recommendations for future projects

*For project management methodologies, see [Agile Methodology](Agile_Methodology.md).*
