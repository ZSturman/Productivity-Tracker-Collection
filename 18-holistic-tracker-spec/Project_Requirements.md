# Project Requirements

## Step 1: Get the Date Joined

- Find the date when the user joined.

## Step 2: Create a List of Dates

- Create a list of dates starting from 30 days before the user joined up to today.

## Step 3: Record the Dates

- For each date in the list, record it in the daily tracker.

## Step 4: Define the Daily Tracker

- Create a daily tracker with the date and the user's ID.

## Step 5: Define Categories

- Define categories such as sleep, nutrition, exercise, mental health, relationships, etc.

## Step 6: Define Topics

- Create topics with names and images.

## Step 7: Define Subtopics

- Create subtopics linked to topics.

## Step 8: Define Subjects

- Create subjects linked to topics and subtopics.

## Step 9: Set Priority

- Allow setting priority levels: whenever, low, medium, or high.

## Step 10: Define To-Do Items

- Create to-do items with details like name, description, images, related topics, priority, and notes.

## Step 11: Define Goals

- Create goals with details like name, description, related topics, and child projects or tasks.

## Step 12: Define Projects

- Create projects with details like name, description, current status, priority, related topics, target completion date, and time allocation.

## Step 13: Define Tasks

- Create tasks with details like name, description, priority, related topics, target completion date, and time allocation.
