# Visualization Techniques

## Charts and Graphs

- **Multi-axis Line Charts**
  - Compare variables with different scales over time (e.g., income vs. work hours).
- **Donut and Pie Charts**
  - Display proportions of categories like time allocation or expense distribution.
- **Area and Streamgraphs**
  - Visualize cumulative data progression and data flow trends.
- **Candlestick Charts**
  - Represent data with high, low, opening, and closing values (useful for financial metrics).
- **Heat Maps and Scatter Plots**
  - Identify patterns and correlations between two or more variables.

## Advanced Visualizations

- **Treemaps**
  - Hierarchical data representation using nested rectangles (e.g., financial breakdowns).
- **Sunburst Diagrams**
  - Multi-level pie charts for visualizing hierarchical data structures.
- **Sankey Diagrams**
  - Show flow and relationships between different data sets (e.g., time spent to outcomes).
- **Radar/Spider Charts**
  - Compare multiple quantitative variables on a single chart.

## Geographical Maps

- **Choropleth Maps**
  - Represent data density or variations over geographical areas (useful for travel data).

## Examples and Use Cases

- **Mood vs. Sleep Quality**
  - Use scatter plots to explore potential correlations.
- **Expense Distribution**
  - Utilize donut charts to visualize spending habits across categories.
- **Time Allocation**
  - Apply Sankey diagrams to illustrate how time investment leads to different outcomes.
