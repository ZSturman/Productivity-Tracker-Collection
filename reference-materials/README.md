# Reference Materials

> iPad sketches, UI mockups, and photographs from the design process.

---

This folder collects visual reference materials that informed the design of various projects in the collection. They're not tied to a single project — they're part of the broader thinking that happened on paper and iPad before (and alongside) the code.

## What's Inside

### [ipad-sketches/](ipad-sketches/)

Screenshots of planning notes and UI mockups captured on iPad. Includes:

- `daily tracker.PNG` — daily tracking dashboard wireframe
- `new_proj_input_form.PNG` — project creation form mockup
- `IMG_6222.PNG` through `IMG_6282.PNG` — various planning notes, UI concepts, and category structures (~17 images)

These represent the kind of exploratory design work that happens before a prototype exists — sketching information architecture, testing layout ideas, and working out what data should go where.

### [action-state-photos/](action-state-photos/)

Photographs from early action-state explorations, predating or complementing the SwiftUI implementations (#10–#16).
