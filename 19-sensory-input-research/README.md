## The Story

Six months after the holistic specification, this folder goes deeper — not into features or requirements, but into the biological machinery underneath all of it. If the earlier research notes asked "what affects focus?", these ask "why does focus work the way it does?"

The brain energy model splits cognition into three systems: the Cortex (which believes it's in charge — handling interest, knowledge, novelty, pressure, future plans), the Limbic system (which actually controls behavior through confidence, mood, stress, and emotional response), and the Lizard Brain (which handles survival basics: health, danger, shelter, diet, sleep, breathing). Each system has its own energy demands and its own influence on focus and retention.

The `Cognitive power.md` document takes this further with a provocative framing: anxiety equals over-analysis with low confidence, and boredom equals expected prediction with minimal analysis. It sketches a full cognitive processing pipeline — sensory input → memory traversal → analysis → prediction → action → expectation → output — and maps energy consumption across each stage.

The Obsidian canvas file (`SensoryInput.canvas`) visualizes this as a flow diagram: Sensory Input leads to Memory, which feeds Analysis, which drives Prediction, then Action, then Expectation, with a feedback loop back to memory storage. It's a model of how the brain processes information — and implicitly, a model of what a tracking system would need to capture to understand attention at a biological level.

These are research notes, not a product. But they represent the deepest theoretical layer in the entire collection.

## What It Does

This is theoretical research, not code. It models:

- **Brain energy distribution** across Cortex, Limbic, and Lizard Brain systems
- **Focus factors per brain system**: what each layer needs to maintain attention
- **Fatigue mitigation strategies** for each system
- **Anxiety and boredom** as functions of analysis intensity vs. confidence
- **Cognitive processing pipeline**: sensory input → memory → analysis → prediction → action
- **Energy consumption breakdown** across processing stages

## What I Learned

That productivity research eventually leads you to neuroscience whether you plan for it or not. Understanding why focus fails requires understanding the systems that produce focus in the first place. The three-layer brain model was particularly useful because it explains why willpower (a Cortex function) so often loses to mood (Limbic) or fatigue (Lizard Brain). You can't optimize a system you don't understand, and this research was my attempt to understand the system that matters most: my own brain.
